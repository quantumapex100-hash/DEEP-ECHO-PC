# DEEP-ECHO 2.3.0

DEEP-ECHO 2.3.0 focuses on a stronger desktop listening experience: upgraded Floating Lyrics and Mini Player controls plus the new Floating Immersive Lyrics panel.

## Highlights
- New **Floating Immersive Lyrics**: a transparent, always-on-top, full-height right-side lyrics panel that stays anchored to the screen edge and resizes leftward.
- Full synchronized multi-line lyrics with auto-follow, playback controls, ±10 second seeking, previous/next, play/pause, and a seek/progress bar.
- Independent Immersive Lyrics settings for panel opacity, lyrics opacity, lyrics size, visualizer ON/OFF, Only Lyrics mode, and click-through.
- Immersive Lyrics settings are also available from the main app Settings screen and synchronize live with the panel.
- Resize/text anti-clipping hardening: long lines wrap safely, narrow widths adapt automatically, and active lyrics no longer scale outside the panel bounds.
- Theme-matched Immersive visualizers for Golden, Light, Dark, Purple/Electric, Toxic, Blood, Silver, Transparent/Glass, Fluids, RGB, Love, Space, and Dragon.
- Immersive visualizers use real analyser data: spectrum, waveform, bass, mids, highs, vocal energy, beat and transient response.
- Dragon Immersive Lyrics reuses DEEP-ECHO's existing dragon artwork and theme identity.
- Floating Lyrics now includes a responsive seek/progress bar, supports resizing up to the full monitor work area width, and has a dedicated frosted White UI skin.
- Mini Player now includes optional synced lyrics, a Lyrics ON/OFF control, and its own responsive seek/progress bar.

## Preserved systems
The 2.3 work was intentionally isolated from DEEP-ECHO's existing playback-start engine, download/recovery safeguards, main lyrics timing clock, classic Floating Lyrics behavior, and core Mini Player playback path.

## Update
Existing DEEP-ECHO users on older versions should receive the normal in-app update prompt after `v2.3.0` becomes the latest published release and `latest.yml` is available with the installer assets.
