# DEEP-ECHO 2.2 END

DEEP-ECHO 2.2 END is the final 2.2 release, shipped internally as version `2.2.8` so automatic updates continue to use normal semantic versioning.

## Highlights
- Distinct theme-native visualizers with theme-specific glow, animation and particles.
- Adjustable visualizer glow presets and reset controls.
- Cleaner lyrics stage with readable future lines and Karaoke visualizer parity.
- Faster staged lyrics loading without changing the core lyric sync clock.
- Romanized lyrics support for Hindi/Devanagari, Punjabi/Gurmukhi and Arabic-script lyrics without translating their meaning.
- Local playlist cards now include Open, Play and Delete; deleting a playlist does not delete downloaded songs.
- Online playlist/collection cards include an explicit Open Songs action so tracks can be inspected and played individually.
- Existing playback, download recovery, queue and auto-update safeguards remain intact.

## Update
Existing DEEP-ECHO users on older versions should receive the normal in-app update prompt when this release becomes the latest published version.
