# DEEP-ECHO 2.2.2 — Search/Home Layout + Exact Word Sync + Version Clarity

- Fixed autocomplete layout collisions in both Home and Search.
- Typing from Home now moves cleanly into Search instead of covering the Home hero.
- Autocomplete is compact, glassy, limited to four visible suggestions and keeps results/discovery separate.
- Added a separate **Word by Word ON/OFF** control in Lyrics.
- YouTube JSON3/VTT caption segment timestamps are used for exact per-word highlighting when available.
- If exact word timing is unavailable or does not match the displayed lyric text reliably, DEEP-ECHO keeps safe line-by-line sync instead of inventing fake word timing.
- Current installed version is always shown in Settings and About.
- What’s New is version-aware and automatically opens once after each newly installed version.
- Keeps v2.2.1 correct-track switching and the faster cached GitHub release workflow.
