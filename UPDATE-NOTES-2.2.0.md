# DEEP-ECHO 2.2.0 — Home 2.0 + Search Discovery

## Home 2.0
- Dynamic Now Playing Pulse inside the Home hero.
- Mood shortcuts for Chill, Workout, Romantic, Focus, Party and Night.
- Quick Picks based on listening signals and recommendations.
- Your Favorites row.
- Available Offline row.
- One-click Refresh Home action.
- Theme-aware visuals that reuse the active DEEP-ECHO palette.

## Search Discovery
- Personalized recommendations shown inside Search before typing.
- Quick search chips based on recents, artists and starter discovery prompts.
- YouTube-style remote search suggestions while typing.
- Ghost completion: press Tab or Right Arrow to accept the suggested completion.
- Keyboard navigation with Up/Down, Enter and Escape.
- Local fallback suggestions if the remote suggestion service is unavailable.

## Safety
- Playback, lyrics, downloads and visualizer engines are not replaced.
- Existing auto-update pipeline remains unchanged.
