DEEP-ECHO v2.0.0 - BUILD FIX PACKAGE
=====================================

Is package me app ke music/UI/features ko change nahi kiya gaya.
Sirf Windows build/install pipeline ko repair kiya gaya hai.

ROOT CAUSE FIXED
----------------
Old Setup-YtDlp.bat me:
    set "TMP=bin\yt-dlp.exe.tmp"
tha.

TMP Windows ka system temporary-directory environment variable hota hai.
Isko file path se overwrite karne ki wajah se:
- yt-dlp/PyInstaller temp extraction break hui
- NSIS makensis !tempfile fail hua
- assistedInstaller.nsh build abort hua

FIXES
-----
1. Setup-YtDlp.bat ab SETLOCAL use karta hai.
2. System TEMP/TMP ko kabhi overwrite nahi karta.
3. yt-dlp download unique file me %TEMP% ke andar hota hai.
4. Download verify hone ke baad hi real yt-dlp replace hota hai.
5. Existing yt-dlp locked ho to known-good copy preserve hoti hai.
6. Purana broken bin\yt-dlp.exe.tmp file/directory clean hota hai.
7. Build-Karo.bat self-elevates to Administrator.
8. Build ke liye isolated safe TEMP/TMP folder use hota hai.
9. Old dist clean hota hai taaki stale installer files mix na hon.
10. Build output build-output.log me automatically save hota hai.
11. Build-Portable.bat fallback diya gaya hai; ye NSIS installer stage skip karke dist\win-unpacked app banata hai.
12. package.json description ASCII-safe ki gayi taaki NSIS console encoding garbage na aaye.
13. Desktop/Start Menu shortcut settings explicit hain; uninstall app data delete nahi karega.

NORMAL BUILD
------------
Double-click:
    Build-Karo.bat

UAC aaye to Yes dabao.
Successful output:
    dist\DEEP-ECHO-2.0.0-Setup.exe

FALLBACK BUILD
--------------
Agar installer stage kisi PC-specific antivirus/NSIS issue se block ho:
    Build-Portable.bat

Output:
    dist\win-unpacked\DEEP-ECHO.exe

IMPORTANT
---------
Build ke waqt DEEP-ECHO ki already running packaged copy close rakhna best hai.
