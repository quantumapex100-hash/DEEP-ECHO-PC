# Theme-aware cinematic startup

Adapted the supplied DeepEcho_Golden_Brown_Cinematic_V6_Logo_Parallax.html visuals into a Shadow DOM overlay. The wave logo, rings, cinematic layers, pointer parallax and expanding square-fringe reveal lead into the existing app surface rising from below. The reference demo interface and audio synthesizer are excluded. Fourteen saved themes control palette, ripple/orbit pacing and pixel-reveal colours/timing.

The real app stays mounted and loads normally behind the overlay. Actual UI, local-library, background-effects and session-completion stages drive progress. The existing session prewarm, restore timing, song/time and playing/paused behavior remain in place. The full 7000 ms intro always plays, with the reference loading-bar easing, then its original 1650 ms cubic pixel reveal and 1300 ms bottom-to-top app entrance. Stage status remains separate from cinematic progress. At 7000 ms, unresolved online restore no longer blocks entry; it continues through the existing resolver. Continue/Escape, reduced-motion, resize and canvas fallback release controls safely. The old native bootstrap surface is transparent to avoid displaying a second splash; the main window now explicitly launches fullscreen; F11 and Escape still exit fullscreen.

Parallax follows display ticks with time-based damping only while its pointer spring moves. Decorative SVGs are reused as local image layers and loading-bar progress uses a transform. Fully covered app surfaces retain layout/loading while skipping redundant painting until shortly before reveal. Reveal uses a bounded canvas and app transform/clip without full-screen animated blur. The overlay, observers, temporary styles, timers and event handlers are removed when it ends. No new media decoder or audio context is created by the intro.

Validation: 557 tests pass plus renderer smoke. New lifecycle tests cover all fourteen saved palettes, actual-stage progress, delayed-session timeout, reduced motion, skip and missing canvas. Native Electron tests verified saved Toxic/Light launch, absence of demo UI, restored local test audio at 12 seconds in paused state, and a deliberately delayed remote stream releasing the app while session completion was still pending. Controls were no longer inert and app transform returned to none. No renderer errors were recorded. Tests use isolated app data and fixture IPC; they do not verify current online YouTube availability or promise hitch-free performance on all hardware.
