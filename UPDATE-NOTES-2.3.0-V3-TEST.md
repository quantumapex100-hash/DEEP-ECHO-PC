# DEEP-ECHO 2.3.0 V3 TEST

## Floating Immersive Lyrics
This test build adds the new **Floating Immersive Lyrics** experience without replacing the existing Floating Lyrics overlay.

- Open it from Lyrics -> **Immersive Lyrics**.
- It stays on the right side from top to bottom and remains always-on-top.
- Resize the width and the right edge remains locked; the panel expands toward the left.
- It displays the full synced lyrics timeline instead of only the current/next line.
- The active lyric follows the same playback clock already used by DEEP-ECHO.
- Includes playback controls and a seek/progress bar.
- Includes a theme-matched real-audio visualizer.
- Settings are independent: UI opacity, lyrics opacity, lyrics size, visualizer toggle, Only Lyrics mode.
- Only Lyrics mode removes the visible panel/background and leaves the lyric experience floating.
- Click-through is independent from classic Floating Lyrics. Toggle it from the overlay; `Ctrl+Alt+Shift+X` can turn it back off while gaming/working.

## Safety / preserved systems
Classic Floating Lyrics, Mini Player, core renderer playback, lyrics engine/timeline, download logic, and existing sync behavior were preserved.

This is a TEST source package. It has not been published as a GitHub release.
